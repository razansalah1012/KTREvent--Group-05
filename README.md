
# KTREvent — Event and Club Management Application

KTREvent is a mobile application developed to support event organization, club activities, and equipment management through a centralized digital platform.

The application uses Flutter for cross-platform interface development and Firebase services for authentication and data management.

## Key Features

- User registration and authentication
- Event creation and management
- Event registration workflows
- Club proposal management
- Equipment management
- Notifications
- Analytics and reporting features
- Certificate management
- PDF generation
- Localization support

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android emulator or physical device
- Firebase project configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/razansalah1012/KTREvent--Group-05.git
   ```

2. Navigate to the project directory:

   ```bash
   cd KTREvent--Group-05
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for the application.
5. Check available devices:

   ```bash
   flutter devices
   ```

6. Run the application:

   ```bash
   flutter run
   ```
